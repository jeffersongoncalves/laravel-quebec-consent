# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0 - 2026-11-17

First release of laravel-quebec-consent: a consent ledger per specific purpose (Quebec Law 25, s. 14), versioned, expiring and withdrawable, with proof (IP and user agent), for users and visitors, with an optional endpoint and claim on login. Part of the Quebec Law 25 suite for Laravel.
